โครงสร้างค่าธรรมเนียม 4 รายการหลักที่ผู้ขายต้องรู้

FEE GUIDE 2569
01 / TRANSACTION

ค่าธรรมเนียมชำระเงิน

คิด 3% + VAT 7% = 3.21% ทุกแพลตฟอร์มเท่ากัน คิดจากยอดเงินรวมที่ผู้ซื้อชำระจริง (รวมค่าส่งที่ลูกค้าจ่าย)

02 / COMMISSION

ค่าคอมมิชชั่นการขาย

คิดตามหมวดหมู่สินค้า (ทั่วไป ~4.28%, แฟชั่น ~5.35%, ไอที ~3.21%) คิดจากราคาสินค้าหลังหักส่วนลดร้านค้า

03 / PROGRAMS

โปรแกรมส่งฟรี & เงินคืน

Shopee CCB+FSS (~5.35%) / LazCoins+FS Max (~4.5%) หรือ TikTok Extra Shipping ช่วยเพิ่มโอกาสปิดการขาย

04 / VAT 7%

ภาษีมูลค่าเพิ่ม

กฎหมายกำหนดให้แพลตฟอร์มหัก VAT 7% จาก "ยอดรวมค่าธรรมเนียมทั้งหมด" ไม่ได้หักจากราคาสินค้าของร้าน

💡

คำถามที่พบบ่อย (SELLER FAQ)

ทำไมบวกราคาเพิ่ม 30% แล้วเวลาขายจริงถึงยังขาดทุนหรือได้เงินไม่เท่าหน้าร้าน?▼
เพราะค่าธรรมเนียมแพลตฟอร์มคิดแบบ Gross Margin (จากยอดขายสุดท้าย) ไม่ได้คิดจากต้นทุนสินค้า เช่น ถ้าขาย 300 บาท แล้วโดนหัก 12% จะเท่ากับหายไป 36 บาททันที หากตั้งราคาด้วยการบวก Markup ทั่วไปโดยไม่กันบับเฟอร์ค่าโค้ดส่วนลดและค่าธรรมเนียม จะทำให้เงินที่เหลือเข้ากระเป๋าต่ำกว่าที่คาดการณ์ไว้
ค่าธรรมเนียมคำนวณจากราคาไหน คิดรวมค่าจัดส่งไหม?▼
ค่าธรรมเนียมธุรกรรมการชำระเงิน (3.21%) จะคิดจาก "ยอดรวมทั้งหมดที่ลูกค้าจ่าย" (ราคาสินค้า + ค่าส่ง) ส่วน ค่าคอมมิชชั่น และ ค่าโปรแกรมพิเศษ จะคิดจากเฉพาะ "ราคาสินค้าหลังหักส่วนลดของผู้ขาย" โดยไม่รวมค่าจัดส่ง
